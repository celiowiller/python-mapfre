Exercícios Práticos de Fixação: Conteúdo Python
------------------------------------------------------------
Exercício 1: Acesso a Elementos com Índices Negativos
Dada a lista a seguir com nomes de carros:

Python
carros = ['Fusca', 'Civic', 'Corolla', 'Mustang', 'Uno', 'Gol']

Sem alterar a lista, escreva os comandos print() para exibir:

O último elemento usando um índice negativo.

O penúltimo elemento usando um índice negativo.

A quantidade total de elementos na lista utilizando a função len().
------------------------------------------------------------
Exercício 2: Fatiamento (Slicing) e Inversão
Dada a lista de dias da semana:

Python
dias = ['Segunda', 'Terça', 'Quarta', 'Quinta', 'Sexta', 'Sábado', 'Domingo']

Utilizando a técnica de fatiamento ([start:stop:step]):

Imprima uma nova lista contendo apenas os dias úteis (de 'Segunda' até 'Sexta').

Imprima a lista inteira invertida (do 'Domingo' até a 'Segunda').

------------------------------------------------------------
Exercício 3: Navegando em Listas Aninhadas (Listas dentro de Listas)
Dada a seguinte estrutura de dados:

Python

dados = [10, 20, ['Maçã', 'Banana', ['Azul', 'Verde', 'Vermelho']], 50]
Escreva o comando print() necessário para acessar e exibir apenas:

A palavra 'Banana'.

A palavra 'Verde'.
------------------------------------------------------------

Exercício 4: Análise com Funções Nativas (min, max e len)
Dada a lista contendo códigos e nomes misturados:


valores = ['100', '20', '5', '800', '1000']

Qual será a saída do comando print(max(valores)) e print(min(valores))? 
(Atenção: observe que os elementos são do tipo String/texto!)

Escreva o código e execute para conferir a sua resposta.

------------------------------------------------------------

Exercício 5: Manipulação Básica de Dicionários
Crie um dicionário chamado aluno que guarde as seguintes informações:

'nome': "Maria"

'curso': "Análise e Desenvolvimento de Sistemas"

'nota': 8.5

Em seguida, faça o seguinte:

Imprima apenas o valor associado à chave 'curso'.

Adicione uma nova chave ao dicionário chamada 'situacao' com o valor "Aprovado".

Imprima o dicionário completo atualizado.
